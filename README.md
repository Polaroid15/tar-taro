# 🔮 ТАР-ТАРО

Шуточные таро-расклады на чистом HTML/CSS/JS — без сборки, фреймворков и бэкенда.
Идеально для GitHub Pages: просто статические файлы.

Все данные пользователя (имя, знак зодиака, история раскладов) хранятся
только в `localStorage` браузера — никуда не отправляются.

## Что внутри

- 22 старших аркана с шуточными толкованиями (прямые и перевёрнутые)
- 4 расклада: карта дня, «было — есть — будет», финансовый прогноз, «да или нет»
- Анимация перемешивания и раскрытия карт
- История раскладов (до 50 последних), удаление по одному и полная очистка
- Совет дня по знаку зодиака (опционально)
- Копирование результата в буфер обмена
- Адаптивная вёрстка, работает на телефоне

## Как выложить на GitHub Pages

1. Создай новый репозиторий (например, `tar-taro`).
2. Загрузи в него `index.html`, `style.css`, `app.js` (README — по желанию).
3. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch** → ветка `main`, папка `/ (root)` → **Save**.
4. Через минуту-две сайт будет доступен по адресу:
   `https://<твой-username>.github.io/tar-taro/`

## Локальный запуск

```bash
python3 -m http.server 8080
# открой http://localhost:8080
```

(можно и просто открыть `index.html` двойным кликом — сборка не нужна)
